# Como importar produtos de uma planilha

## Descrição

A importação por planilha no ERP da Olist cadastra produtos a partir de um arquivo. Você baixa a planilha modelo, preenche os produtos e envia o arquivo na tela **Importação de produtos via planilha**.

Para abrir a tela, acesse a lista de produtos, com **Cadastros** no menu lateral do ERP, e clique em **Mais ações > Importar produtos de uma planilha**.

## Pré-requisitos

- Acesso à lista de produtos no ERP, com **Cadastros** visível no menu lateral.
- Permissão de produtos para acessar a importação de produtos por planilha.
- Permissão de importação de registros e permissão para incluir e editar produtos.
- Arquivo Excel (.xls ou.xlsx) ou texto (.csv), de no máximo 2 Mb, a partir da planilha modelo.

## Importante

- A planilha precisa seguir o layout de importação de produtos, com a mesma quantidade de colunas.
- O preço promocional só é importado pela planilha quando a empresa possui o módulo de preço promocional.
- A variação só é vinculada ao produto pai se ele já estiver cadastrado com o código (SKU) informado.
- Cada nível de variação deve ser informado como tipo e valor separados por dois-pontos, com no máximo 5 níveis separados por duas barras verticais.
- O estoque não é atualizado para kits nem para produtos do tipo variações.
- O fornecedor só é vinculado ao produto se já existir um contato cadastrado com o mesmo nome.

## Instruções

1. Acesse a lista de produtos, com **Cadastros** no menu lateral do ERP.
2. Clique em **Mais ações > Importar produtos de uma planilha**.
3. No passo 1 da tela **Importação de produtos via planilha**, clique em **baixar planilha**.
4. Preencha a planilha modelo com os produtos. Se precisar de ajuda no preenchimento, consulte **Orientações**, acesse o link **Dicas para preencher corretamente** e as **perguntas frequentes** da mesma tela.
5. No passo 2, clique em **enviar planilha** para importar o arquivo.

## Informações adicionais

### O produto pode ser criado e atualizado por estes canais

- Interface/Tela: criar sim, atualizar sim
- Lote (Planilha): criar sim, atualizar sim
- API V3: criar sim, atualizar sim
- Lis: criar sim, atualizar sim
