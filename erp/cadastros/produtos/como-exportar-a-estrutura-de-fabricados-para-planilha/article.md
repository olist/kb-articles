# Como exportar a estrutura de fabricados para planilha

## Descrição

No ERP da Olist, a lista de produtos oferece a ação **Exportar estrutura de fabricados para planilha**. Com ela, você exporta a estrutura dos produtos fabricados para uma planilha.

Na lista de produtos, com **Cadastros** no menu lateral, o caminho é **Mais ações > Exportar estrutura de fabricados para planilha**.

## Pré-requisitos

- Acesso à lista de produtos no ERP, com **Cadastros** no menu lateral.

## Instruções

1. Acesse a lista de produtos, com **Cadastros** no menu lateral do ERP.
2. Clique em **Mais ações**.
3. Clique em **Exportar estrutura de fabricados para planilha**.

## Informações adicionais

### As exportações da lista são ações distintas

Em **Mais ações** também estão **Exportar produtos para planilha** e **Exportar composição de kits para planilha**. Para a estrutura dos fabricados, use **Exportar estrutura de fabricados para planilha**.
