# Como exportar produtos para planilha

## Descrição

**Exportar produtos para planilha** é uma ação de **Mais ações** na lista de produtos do ERP da Olist. Com ela, você exporta os produtos para uma planilha.

Para chegar à ação, abra a lista de produtos, com **Cadastros** no menu lateral do ERP.

## Pré-requisitos

Tenha acesso à lista de produtos no ERP, com o item **Cadastros** visível no menu lateral.

## Instruções

1. Acesse a lista de produtos, com **Cadastros** no menu lateral do ERP.
2. Clique em **Mais ações**.
3. Clique em **Exportar produtos para planilha**.
